## 🚀 Overview

A high-fidelity personal portfolio engineered for visual impact and technical precision. This project showcases the intersection of **Frontend Architecture** and **Web3 Creative Strategy**, featuring immersive animations, sophisticated typography, and a "performance-first" mobile experience.

Built with **React**, **TypeScript**, and **Framer Motion**, the site explores advanced UI patterns including scroll-bound parallax, spring-physics smoothing, and hardware-accelerated rendering.

## 🛠️ Tech Stack

- **Framework:** [React 18](https://reactjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Fonts:** Instrument Serif & Inter (via Google Fonts)

## ✨ Key Features

- **Immersive Hero Section:** Interactive parallax labels and 3D-space floating elements with optimized mobile performance.
- **Dynamic Content Gallery:** Categorized "Selected Work" with high-contrast editorial typography and case study vault.
- **Micro-interactions:** Custom mouse-following cursor (desktop), spring-animated transitions, and sophisticated grain overlays.
- **Mobile Optimized:** Decoupled animation loops and GPU-forced layering for 60FPS scrolling on mobile browsers.
- **SEO Ready:** Optimized meta-tags and semantic HTML5 structure for maximum visibility.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Adeolu05/pda.git
   cd pda
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
